# E-Commerce Sales Analysis using MySQL
Real-World Project | IBM SQL for Data Science Certificate

## Overview:
Analyzed sales data for a Hyderabad-based e-commerce store to find top city, top category, and top customer.

## Database Tables:
1. Customers (Customer_ID, Customer_Name, City)
2. Products (Product_ID, Product_Name, Category, Price)
3. Orders (Order_ID, Customer_ID, Product_ID, Quantity)

## Business Questions Solved:
1. Which city gives highest revenue? 
2. Which category sells most?
3. Who is our most valuable customer?
4. Monthly sales trend
5. Customers who never bought Electronics

## Key Output / Insights:
- Top City: Hyderabad - Rs.62,000
- Top Category: Electronics
- Top Customer: Sravani - Rs.55,000

## Tools Used:
MySQL, JOINS, GROUP BY, Subqueries, Aggregation
